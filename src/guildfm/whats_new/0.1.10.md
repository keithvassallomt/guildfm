## Fresher talk shows

The DJs on a talk station no longer come back to the same stories every day. Each show remembers what the last few talked about, and each DJ brings only one or two of their favourite subjects to any one show, so Debbie's missing yoghurts turn up now and then rather than every morning.

## Stations start straight away

Putting a station on now starts its music straight away with a song it has played before, instead of a silence while it picks its first songs.

## Script prompts are a guide

A talk station's script prompt is now a guide, not a checklist: the DJs keep to its spirit but can wander for variety, so a show won't always use everything in it. Anything in **How they get on** comes up in every show, so keep running jokes in a DJ's pet peeves, soft spots and running obsession, which are shared out a show at a time. See [Talk stations](topic:talk-stations).
:::
