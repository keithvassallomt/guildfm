**Best Voted** is a playlist that looks after itself. When a request gets more than five thumbs up, it joins Best Voted.

![Best Voted](shot:best-voted)

- It holds up to 50 songs. When it's full, a newcomer replaces the song with the fewest thumbs up (the oldest, if several are level), as long as the newcomer has at least as many.
- The number beside each song is how many thumbs up it got.
- It's on **Shuffle** to start with. Put it on like any other playlist.
- You can take a song out with its **×**, but songs can't be added by hand, and Best Voted can't be renamed or deleted.

::: needs change_settings
The numbers can be changed in [Settings](topic:settings), under **Best Voted playlist**.
:::
::: lacks change_settings
An admin can change those numbers.
:::
